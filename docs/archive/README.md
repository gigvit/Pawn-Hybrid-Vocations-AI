# Historical Knowledge Archive

Эта папка хранит длинную базу знаний проекта. Верхнеуровневые документы в `docs/` являются текущим entry point, а файлы здесь нужны для глубокого восстановления контекста.

Содержимое:

- `KNOWLEDGE_BASE_RU.md`: основная русская историческая база.
- `KNOWLEDGE_BASE_EN.md`: английская версия/срез исторической базы.
- `KNOWLEDGE_BASE_LEGACY.md`: самый старый legacy knowledge base до финальной консолидации.

Важно: это архив решений, гипотез, ошибок и live-evidence. При возобновлении разработки сначала читать `docs/ARCHIVE_HANDOFF_RU.md`, затем обращаться сюда за деталями.
